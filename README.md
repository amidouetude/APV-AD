APV_AD_Project
===============

Overview
--------
This repository implements models and notebooks for evaluating integrated agrivoltaic (APV) + anaerobic digestion (AD) systems and optimizing design variables using a combined eLER objective (crop yield, PV production, and biogas). The pipeline is organized as a sequence of notebooks that: prepare data, define physical models, run optimizations, post-process results and produce figures used in the manuscript.

Key features
- Modular physical models (solar geometry, shading, POA, bifacial PV, crop PAR model, ET savings, anaerobic digestion energy balance).
- Models are implemented interactively in notebooks and exported as an importable script for optimization.
- Unit tests for representative designs are embedded in the simulation notebook and have been used to validate the models.
- An associated LaTeX manuscript in paper/ documents methods and results.

Quick start (recommended)
-------------------------
1. Create a Python virtual environment (recommended: venv or conda). Example using venv:

   Windows (PowerShell):
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

   Or using conda:
   ```bash
   conda create -n apvad python=3.10
   conda activate apvad
   pip install -r requirements.txt
   ```

2. Open the notebooks in your preferred Jupyter environment (JupyterLab, classic notebook, or VS Code).

3. Run the notebooks in order:
   - 01_load_data.ipynb  — prepare hourly climate CSVs used by the pipeline.
   - 02_simulation.ipynb — defines physical models, runs unit tests, and exports simulation_functions.py
   - 03_optimizer.ipynb  — runs Differential Evolution optimization and local polishing using exported functions
   - 04_metrics.ipynb    — postprocesses optimized results and writes outputs/csv/results_summary.csv
   - 05_figures.ipynb    — produce plots for the manuscript
   - 06_validation.ipynb — validation checks conducted in the analysis

Important: run 02_simulation.ipynb before 03_optimizer.ipynb because 02 exports simulation_functions.py. The exported file has a header: "Auto-generated by 02_simulation.ipynb — DO NOT EDIT MANUALLY"; to change model code, edit the notebook and re-run the export cell.

Files & structure
-----------------
- notebooks/
  - config_00.py        : central configuration (SITES, PARAMS, DE_SETTINGS, SCENARIOS)
  - 01_load_data.ipynb   : ingest and prepare hourly climate data (writes hourly_{site}.csv in data/)
  - 02_simulation.ipynb : defines physics models & unit tests; exports simulation_functions.py

  - 06_validation.ipynb : validation checks and sensitivity analyses

- outputs/              : generated results and figures (may be created by notebooks)
- paper/                : LaTeX manuscript and sections

Reproducibility notes
---------------------
- This repository did not include a requirements file prior to this change. requirements.txt has been added to provide pinned package versions for reproducible runs.
- Kernel metadata in notebooks indicated "Python (APVAD)" and Python 3.14.5; some packages may have limited support for bleeding-edge Python versions. Use a conservative Python (3.10–3.12) for maximum compatibility or ensure your environment matches kernel version.

Data expectations
-----------------
- The loader expects files named hourly_{site}.csv in the directory referenced by CSV_DIR in config_00.py.
- Expected columns used by the pipeline include (at least): GHI, DNI, DHI, T2m, WS, and optionally ET0 for improved water calculations. Confirm column names and units before running.

Testing
-------
- Unit tests are embedded in 02_simulation.ipynb and are executed when the notebook is run interactively. They validate representative design vectors for the sites and print PASS/FAIL diagnostics.
- A pytest-based test suite is recommended (not included by default). To create tests:
  - Write small deterministic tests for compute_solar_angles, compute_shading, compute_POA, compute_PV, compute_crop_yield, compute_ET_reduction, compute_AD, and eLER_objective using synthetic inputs.
  - Run: pytest -q

Optional: higher-fidelity options
---------------------------------
- pvlib can be used for more accurate solar geometry and irradiance (angle of incidence, transposition models, clear-sky). If you want to adopt pvlib, install it (commented in requirements.txt) and update compute_POA to use pvlib routines. Expect small-to-moderate changes in PV yields when switching models; perform controlled comparisons.
- Replace ET0 proxy with Penman–Monteith when RH/wind-speed data are available for better crop-water estimations.

Troubleshooting
---------------
- If a notebook raises FileNotFoundError about hourly_{site}.csv: run 01_load_data.ipynb first and ensure CSV_DIR in config_00.py points to the correct folder.
- If simulation_functions.py is out-of-sync with the notebook, re-run the export cell in 02_simulation.ipynb (the notebook prints the path where simulation_functions.py is saved).
- If package import errors occur, create a fresh virtual environment and install requirements.txt as shown above.
